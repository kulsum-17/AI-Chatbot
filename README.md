🎓 AI Academic Mentor & Marks Predictor

An interactive Streamlit-based web application that helps students in two ways:

📊 Predict academic marks based on study habits using a Machine Learning model

💬 Chat with an AI Academic Mentor for guidance, explanations, and study advice

This project combines Machine Learning and LLM-powered chatbot in a single application.



🛠️ Tech Stack

1.Python

2.Streamlit – Web application framework

3.scikit-learn – Machine Learning

4.Joblib – Model persistence

5.Groq API – Large Language Model

6.python-dotenv – Secure environment variable handling
